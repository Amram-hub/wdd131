WDD 131 - Ponder: Filtering and Sorting

Open index.html in your browser, or use VS Code Live Server.
Keep index.html, styles.css, and hikes.js in the same folder.

Features:
- One random hike on first load
- Search names, descriptions, and tags (case insensitive)
- Results sorted by numeric distance, shortest first
- Five difficulty icons with boots and placeholders
- Search with the button or Enter
- Empty search shows every hike
- No-results message
- Responsive cards and expandable directions

The five hike records and image URLs come from the supplied course starter.
Images require internet access. Directions are included as supplied by the course.
The course example sorts by difficulty; this version follows the written
requirement to sort by distance.
