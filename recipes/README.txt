Recipe Book Part 2

Extract this ZIP. Copy the recipes folder into your wdd131 project, replacing the existing recipes folder.
Open recipes/index.html to preview. No installation or server is required.

The page shows one random recipe when loaded. Search with the button or Enter. Search matches the name, description, and tags, ignores case, and sorts results alphabetically. Multiple keywords must all match. An empty search shows all eight recipes.

Commit and push your changes, then verify your GitHub Pages site before submitting:
https://amram-hub.github.io/wdd131/recipes/

Files: index.html, styles.css, main.js (templates and search), recipes.js (provided data), images/.
